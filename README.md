# 🏀 バスケ シュート確率記録 bot（LINE / LIFF）

コート図のスポットをタップして「メイク数 / 試投数」を記録し、
自分・チームのシュート確率、月ごとの推移、スポット追加までできる LINE ミニアプリです。

## 構成

```
LINEアプリ ──> LIFFミニアプリ(index.html)  … GitHub Pages などに配置
                     │ fetch(JSON)
                     ▼
              GAS ウェブアプリ(Code.gs)  … JSON API
                     │
                     ▼
          Google スプレッドシート          … DB（Spots / Shots）
```

- **フロント**: `index.html`（1ファイル完結。Chart.js と LIFF SDK は CDN 読み込み）
- **バックエンド**: `gas/Code.gs`
- **DB**: スプレッドシート（初回アクセス時に `Spots` `Shots` シートと既定5スポットを自動作成）

---

## セットアップ手順

### 1. スプレッドシート + GAS を用意

1. [Google スプレッドシート](https://sheets.new) を新規作成（名前は任意）
2. メニュー **拡張機能 → Apps Script** を開く
3. 既定の `コード.gs` を全消しして、`gas/Code.gs` の中身を貼り付けて保存
4. （任意）エディタで関数 `setup` を一度実行 → `Spots` `Shots` シートが作られる
   - 初回は権限の承認ダイアログが出るので許可する

### 2. GAS をウェブアプリとしてデプロイ

1. Apps Script 右上 **デプロイ → 新しいデプロイ**
2. 種類：**ウェブアプリ**
3. 設定：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. デプロイして表示される **ウェブアプリ URL（`https://script.google.com/macros/s/.../exec`）** をコピー
   - ⚠️ コードを直したら、**「デプロイを管理」→ 鉛筆 → バージョン: 新バージョン** で再デプロイが必要（URL は変わりません）

### 3. フロントをホスティング（HTTPS 必須）

LIFF は HTTPS ページしか登録できません。おすすめは **GitHub Pages**（無料）。

1. GitHub でリポジトリを作り、`index.html` をアップロード
2. **Settings → Pages → Branch: main / (root)** で公開
3. 公開 URL（例：`https://<ユーザー名>.github.io/<リポジトリ>/`）をメモ

> Netlify Drop / Cloudflare Pages でも可。とにかく `index.html` を HTTPS で開ければOK。

### 4. LINE 側（LIFF アプリ）を作成

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログイン
2. **プロバイダー**を作成（例：MyTeam）
3. **新規チャネル → LINEログイン** を作成
4. チャネル内 **LIFF タブ → 追加**：
   - エンドポイント URL：**手順3の GitHub Pages URL**
   - サイズ：**Full**
   - スコープ：**profile**, **openid** にチェック
5. 生成された **LIFF ID**（`1234567890-abcdEFGH` の形）をコピー

### 5. フロントに URL / ID を設定

`index.html` の上部を編集：

```js
var LIFF_ID = 'ここに手順4のLIFF ID';
var GAS_URL = 'ここに手順2のウェブアプリURL(/exec)';
var API_TOKEN = ''; // 使わないなら空のまま
```

編集後、GitHub Pages に再アップロード（上書き）。

### 6. 使ってみる

- LIFF の起動 URL は **`https://liff.line.me/<LIFF ID>`**
- この URL を LINE グループやトークに貼れば、メンバーがタップして記録できます
- （任意）LINE 公式アカウント（Messaging API チャネル）を作り、**リッチメニュー**からこの LIFF URL を開くようにすると導線が良くなります

## 使い方

| タブ | できること |
|------|-----------|
| 🏀 記録 | コートのスポットをタップ → 試投数・メイク数を入力して保存。ドット内に今月の成績を表示 |
| 📊 マイ | 自分のスポット別確率（選択中の月／全期間） |
| 👥 チーム | メンバーの確率ランキング。スポット別／合計を切替 |
| 📈 推移 | スポットを選ぶと月ごとの確率を折れ線グラフ＋前月比で表示（自分／チーム切替） |
| ⚙️ 設定 | コートをタップして位置を決め、名前を付けて**新スポット追加**。既存スポットの削除も |

右上の**月セレクタ**で対象月を切り替えられます（「全期間」も選べます）。

## データ構造（スプレッドシート）

**Spots** … スポット定義
| id | name | x | y | order | active | createdAt |
|----|------|---|---|-------|--------|-----------|

**Shots** … 記録
| id | timestamp | ym | date | userId | displayName | spotId | makes | attempts |
|----|-----------|----|----|--------|-------------|--------|-------|----------|

- スポット削除は `active=false` の論理削除。過去の記録は残ります。
- 集計は GAS 側で毎回計算（数百〜数千件なら十分高速）。

---

## よくあるハマりどころ

- **保存できない / データが出ない**：GAS を「新バージョン」で再デプロイしたか確認。GAS_URL は末尾 `/exec`（`/dev` ではない）。
- **画面が真っ白**：`LIFF_ID` / `GAS_URL` が未設定、または LIFF エンドポイント URL と実際の公開 URL が不一致。
- **PC ブラウザで確認したい**：LINE 外で開くと自動でテストユーザーになり、記録・集計を試せます（LIFF ログインはスキップ）。
- **表示名が古い**：`displayName` は記録時点の名前を保存。最新記録の名前が一覧に反映されます。

---

## カスタマイズの入口

- 既定スポットの変更：`Code.gs` の `DEFAULT_SPOTS`
- 2P スポットや距離別を増やす：設定タブから追加するだけ（コート上の好きな位置に置けます）
- 簡易パスワード：`Code.gs` の `API_TOKEN` と `index.html` の `API_TOKEN` を同じ文字列にすると、URL を知っている人だけが書き込めます
